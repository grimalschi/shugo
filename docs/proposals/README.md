# Proposals

Here lies what Shugo does not have yet: proposals that are waiting for the decision of the author of the project, and postponed. When the proposal is accepted and made, his decisions go to [specification](../../spec/README.md) - how to use Shugo - and [description of device](../README.md).

| Proposal | About what | Status |
| --- | --- | --- |
| [Live Reload](live-reload.md) | Development mode: the open page is calculated first, only the changed one is rebooted, styles are replaced without rebooting, the error is visible in the browser | waiting for decisions |
| [Data adapter](data-adapter.md) | How data from any source gets into the project database: full load with comparison, point changes, a scheme that gives a signal | waiting for decisions |
| [Pictures](images.md) | Built-in compression with WebP and optional libvips for speed and AVIF; addresses, export, cache | waiting for decisions |
| [Internationalization](i18n.md) | One page for all languages, lines in JSON, addresses `/about` and `/en/about`, optional parameter `[[lang]]` | waiting for decisions |
| [Comparisons and windows in readings](range-queries.md) | Accurate update of comparison queries and `limit`: Reading boundaries and R*Tree index | postponed |
